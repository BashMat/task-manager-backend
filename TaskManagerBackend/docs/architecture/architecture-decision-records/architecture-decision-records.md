# Architecture Decision Records

## About

This section provides collection of `Architecture Decision Records (ADRs)` – documentation regarding
actual decisions, their context, reasons behind them and their consequences.

## Structure

This section is structured as follows:

- `architecture-decision-records` – root directory.
    - `./architecture-decision-records.md` – introduction file.
    - `./{yyyy}-{mm}-{dd}-{order}-{title}` – directory for specific `ADR` content.
      - `./{yyyy}-{mm}-{dd}-{order}-{title}.json` – `.json` metadata file for this `ADR`.
      - `./{yyyy}-{mm}-{dd}-{order}-{title}.md` – main `.md` file for this `ADR`.
      - `./media` – directory for media files used in this `ADR`, like diagrams.
    - `./{yyyy}-{mm}-{dd}-{order}-{title}`
